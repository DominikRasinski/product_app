# Uruchomienie projektu

### komendy
`sudo systemctl start mariadb` - uruchomienie systemowo serwera mariaDB

`sudo mariadb -u root -p` - zalogowanie się bazy danych miaraDB

#### mailpit
`usr/local/bin/` - przejście do standardowej ścieżki instalacji

oraz należy uruchomić usługę za pomocą `./mailpit`
